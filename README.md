# Café Dali — prototipo web

## Ejecución
Extraer el ZIP completo y abrir `index.html` en un navegador moderno. No requiere servidor, Internet, librerías ni instalación. Mantener la carpeta `assets` junto al HTML.

## Módulos
- Inicio: presentación, recomendaciones y acceso a eventos.
- Menú: 12 productos ficticios en cuatro categorías, búsqueda y filtros.
- Eventos: datos de evento y contacto, paquetes, extras, cálculo interactivo y generación de una cotización preliminar imprimible.

## Archivos
- `index.html`: estructura y vistas.
- `styles.css`: estilos responsivos, estados y formato de impresión.
- `app.js`: navegación, catálogo, filtros, validación y cálculo de cotización.
- `assets/`: ilustraciones SVG locales.

## Reglas de demostración
Uso de espacio: Q300 por 2 horas, Q100 por cada hora adicional. Capacidad ilustrativa: 5 a 40 personas. Paquetes por persona: Q0, Q35, Q55 y Q75; decoración Q150; mesa de bienvenida Q100. El nombre comercial, precios, capacidad, ilustraciones y paquetes son provisionales. Los datos de contacto no se envían ni se guardan; no se comprueba disponibilidad ni se crea una reserva. No hay pagos, API ni base de datos.
